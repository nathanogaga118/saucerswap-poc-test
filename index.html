Hedera Custom Fee PoC

Controlled Hedera Testnet research demonstration
HEDERA TESTNET ONLY
This demonstration is intended to evaluate how a wallet presents the economic effects of a token transfer containing a native custom fee.
Network Hedera Testnet
Victim account 0.0.10034285
Token 0.0.10037892
Amount 1 token
Fee collector 0.0.10015061
Native token custom fee 7 HBAR plus the ordinary Hedera transaction fee.
Wallet not connected.
Research procedure: compare the fee information displayed by the wallet's signing interface with the native custom-fee configuration recorded on Hedera Testnet. Do not approve a transaction unless the resulting economic effect is understood.
